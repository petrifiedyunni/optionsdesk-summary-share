Long Equity Desk Not active · dry-run

Purpose
  • Scan US / HK / SG for swing setups
  • Score with EMA / RSI / MACD / volume / ATR
  • Size by risk, journal every trade, backtest edge
  • Telegram YES/NO overnight loop — no live stock orders

Pipeline

Market data→ Signals→ Confirming gate→ Size & journal→ Supervised (dry-run)→ Scale-out / trail
modules/
  • ibkr_client — TWS connect; clientId pool; --paper → 7497
  • scanner — multi-market scan pipeline
  • signals — indicator scoring (0–100)
  • sizer — stock + option risk sizing
  • journal — SQLite trade log
  • equity_paper_book — simulated fills + scale-out state
engine / desk / helpers
  • supervised.py — overnight loop, Kelly, news
  • confirming_signals — optional paid overlays
  • trade_manager — 1R / 2R scale-out + trail
  • telegram_bot — alerts & emergency cmds
  • backtester/ — replay, metrics, regime
Rule Detail
Pre-filter Must pass ≥3 of 5: price > $5, vol spike > 1.2×, not down > 8% DoD, min volume, positive close
Liquidity 20d avg vol ≥ 500k, price ≥ $10, dollar volume ≥ $5m
Scorecard EMA21/50/200, EMA8×21 cross, RSI 50–65, MACD turn, volume > 1.3× → Strong Buy ≥ 95
Stop / targets Stop = max(EMA21, price − 1.5 ATR) · T1 1.5R · T2 2.5R
Managed exits Scale out 33% at 1R and 2R, then trail remaining
Sizing 3% risk default, 5% hard cap · size = risk budget / stop distance
Launch
  • python main.py --live-supervised — dry-run even with --execute
  • Do not run engine/supervised.py directly (path / config import)

OptionsDesk CSP Live · v2

Purpose
  • Sell cash-secured puts when IV rank is elevated
  • SPY regime gate blocks hostile tape
  • Frozen hypothesis — retune = new version
  • Telegram auto-approve optional; STOP / PAUSE / PANIC always on
HYPOTHESIS_V2 · active
  • Entry — IVR ≥ 70 · ~0.25Δ put · 7–14 DTE (target 10) · spread ≤ 20% of mid
  • Exits — take profit 50% of credit · stop at 2× premium · mark = live ask
  • Risk — max 5 positions · max 15 new/week · ≤5% capital / trade · sleeve ≤ 80% NAV
  • Dedupe — one underlying at a time (ticker + live short-put check), not strike
  • Skip — earnings within 5 days (Sleeve E owns that) · no-bid / illiquid chain
  • Regime — block bear & high-vol choppy · reduced size in ranging

Live path

Universe (top 100)→ IV Rank + regime→ Build CSP→ Ticker dedupe→ Approve / auto→ Execute + 50%/2×
optionsdesk/ + engine/
  • scanner — universe → candidates by IVR / liquidity / capital
  • regime_gate — SPY ADX + VIX percentile → scalar / block (V2)
  • trade_builder — strike, DTE, collateral; skip empty quotes
  • executor — live sell-put / buy-to-close; ticker keys in the fill log
  • capital_pool — collateral vs IB NetLiq + sleeve %
  • optionsdesk_supervised — scan / exit / heartbeat loop

Sleeve E · Earnings IV Crush Live

Purpose
  • Own the 1–3 DTE earnings window that CSP explicitly skips
  • Default structure is a defined-risk vertical (put credit if bullish, call credit if bearish)
  • Naked CSP only with explicit Telegram YES NAKED when implied move is small
  • Unconditional morning-after close to harvest crush
EARNINGS_SLEEVE_V1 · registered 2026-08-03
  • Window — 1–3 days to earnings · universe top 200 liquid (or pinned watchlist)
  • IVR — ≥ 65 · skip if implied move > 25%
  • Short delta — ~0.22 · wing ~8% away
  • Naked flag — implied move < 15% then human override
  • Exits — 50% / 2× in session · 30% target morning after print
  • Size — 2% NAV risk on spread max-loss · 5% NAV collateral if naked · max 5 contracts

Live path

Liquid universe→ Earnings calendar→ IVR + implied move→ Build vertical→ Telegram YES→ Hold through print→ Close AM after
Code
  • sleeve_e_supervisor — scan / approve / exit loop
  • sleeve_e_signal — direction + structure
  • earnings_researcher — card for Telegram
  • IVHistoryCache — IVR for the name
Ops
  • Skips IB clientId 5 (CSP) and takes next free pool id
  • State in data/sleeve_e_positions.json
  • Does not share Telegram approval IDs with CSP
Launch
  • python engine/sleeve_e_supervisor.py --execute --live-account --universe-size 200

VOLHARVEST Paper · live locked

Purpose
  • Same vol-risk premium, defined-risk only (iron condors / wings)
  • Risk Officer rejects CSP / naked shorts in this path
  • Papers beside live OptionsDesk + Sleeve E until gate clears

Architecture

Design
  • Not microservices — one process family sharing IBKR + Telegram
  • Desks are packages with hard risk boundaries and separate clientIds
  • CSP never enters VOLHARVEST — Risk Officer enforces it there
  • Sleeve E is the live earnings path; VOLHARVEST A remains the paper / defined-risk sibling
  • Paper vs live is coded, not just convention
